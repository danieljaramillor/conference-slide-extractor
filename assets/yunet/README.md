# YuNet OpenCV face detection model

The application uses the March 2023 YuNet model from the [OpenCV Model Zoo](https://github.com/opencv/opencv_zoo/tree/47534e27c9851bb1128ccc0102f1145e27f23f98/models/face_detection_yunet). The model runs locally with OpenCV DNN. See the [upstream MIT license](LICENSE).
