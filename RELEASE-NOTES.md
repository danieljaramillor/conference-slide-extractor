# Conference Slide Extractor 2.3.0

- Retains small slide reveals, such as a late chart panel, when the more complete capture preserves the earlier content.
- Recovers visible projected slides inside supported stage camera layouts and flags their native resolution.
- Opens Save As for export in supported browsers, with a download fallback.

Download `ConferenceSlideExtractor-Windows-x64.exe` under **Assets** and double-click it. See the repository README for storage, Windows Server, and command-line use. Use `SHA256SUMS.txt` to verify the download. The Windows executable is unsigned.
