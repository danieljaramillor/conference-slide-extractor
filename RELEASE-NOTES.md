# Conference Slide Extractor 2.14.0

- Reconstructs table rows using aligned labels and values within the table region, including two-column layouts.
- Runs higher-resolution OCR on selected slide images with small text during export.
- Recovers bare printed page numbers when adjacent slides support the same incrementing footer sequence.
- Rescan a ZIP or export a reviewed deck again to generate updated text and tables.

Download `ConferenceSlideExtractor-Windows-x64.exe` under **Assets** and double-click it. See the repository README for storage, Windows Server, and command-line use. Use `SHA256SUMS.txt` to verify the download. The Windows executable is unsigned.
