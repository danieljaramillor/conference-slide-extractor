# Conference Slide Extractor 2.9.0

- Groups related slide suggestions in **Review builds** with capture previews and a side-by-side comparison.
- Highlights where slide content differs and suggests a more complete capture when the evidence supports it.
- Lets reviewers adjust the slide crop in place when a broadcast frame includes a presenter window.
- Keeps individual review decisions and protects captures that show materially different content.

Download `ConferenceSlideExtractor-Windows-x64.exe` under **Assets** and double-click it. See the repository README for storage, Windows Server, and command-line use. Use `SHA256SUMS.txt` to verify the download. The Windows executable is unsigned.
