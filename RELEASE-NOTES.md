# Conference Slide Extractor 2.11.0

- Keeps both slide versions when a heading, callout, or other localized content is replaced. For additive builds, it keeps the most complete capture.
- Uses table-cell position and native pixels to resolve disputed OCR readings. A targeted OCR pass checks tiny changes that can disappear in the full-slide preview.
- Runs OCR for newly selected captures before writing the initial slides and text files.
- Rescan an existing source ZIP to apply the updated grouping and OCR checks.

Download `ConferenceSlideExtractor-Windows-x64.exe` under **Assets** and double-click it. See the repository README for storage, Windows Server, and command-line use. Use `SHA256SUMS.txt` to verify the download. The Windows executable is unsigned.
