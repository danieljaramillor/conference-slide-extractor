# Conference Slide Extractor 2.2.0

- Download and run the single Windows x64 executable. Python and the offline OCR models are included.
- Compare possible duplicates and builds side by side. Keep both slides, merge and retain either capture, skip a pair, or undo the last decision.
- Review crop and readability issues separately. Review decisions stay with the batch and exports include source images, slides, text, and a source mapping.

Download `ConferenceSlideExtractor-Windows-x64.exe` under **Assets** and double-click it. See the repository README for storage, Windows Server, and command-line use. Use `SHA256SUMS.txt` to verify the download. The Windows executable is unsigned.
