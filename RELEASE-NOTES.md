# Conference Slide Extractor 2.5.0

- Guided review in four steps. Compare pairs, resolve slide issues, review the deck in export order, and save the ZIP.
- Check one flagged slide at a time with a large preview, plain-language quality checks, and direct controls for cropping, changing captures, approving, or excluding.
- Return to any new issue a deck edit creates before exporting.

Download `ConferenceSlideExtractor-Windows-x64.exe` under **Assets** and double-click it. See the repository README for storage, Windows Server, and command-line use. Use `SHA256SUMS.txt` to verify the download. The Windows executable is unsigned.
