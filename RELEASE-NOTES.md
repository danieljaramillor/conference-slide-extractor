# Conference Slide Extractor 2.6.0

- Excludes clear speaker-only camera shots using a bundled local model and sends uncertain captures to Slide issues.
- Brings excluded captures into a dedicated review view with an explicit restore action. Merge and split actions respect exclusions.
- Tests the compiled Windows app through ZIP intake, review, offline OCR, and export before attaching release assets.

Download `ConferenceSlideExtractor-Windows-x64.exe` under **Assets** and double-click it. See the repository README for storage, Windows Server, and command-line use. Use `SHA256SUMS.txt` to verify the download. The Windows executable is unsigned.
