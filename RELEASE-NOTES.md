# Conference Slide Extractor 2.7.0

- Automatically omits clear overlaps between neighboring slides, including some blends where the incoming slide changes size.
- Selects the fully visible capture when a slide build fades in. Changed numbers or replacement content can remain separate.
- Labels detected blends in **Review excluded captures** and verifies both clean slide exports in the packaged Windows tests.

Download `ConferenceSlideExtractor-Windows-x64.exe` under **Assets** and double-click it. See the repository README for storage, Windows Server, and command-line use. Use `SHA256SUMS.txt` to verify the download. The Windows executable is unsigned.
