# Conference Slide Extractor 2.4.0

- A glass-style dashboard with drag-and-drop ZIP selection and a clearer batch list.
- A redesigned review workspace with side-by-side captures, remaining pair and issue counts, and a prominent export button.
- The same Windows executable runs the interface and offline extraction together.

Download `ConferenceSlideExtractor-Windows-x64.exe` under **Assets** and double-click it. See the repository README for storage, Windows Server, and command-line use. Use `SHA256SUMS.txt` to verify the download. The Windows executable is unsigned.
